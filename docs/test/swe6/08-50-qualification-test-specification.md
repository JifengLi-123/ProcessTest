## テスト方針

SWE.6 は **SW 要求仕様書（17-11）に対する適格性確認**である。各テストケースは SW-REQ と検証基準（17-50 の VC）に 1 対 1 で対応付け、合否判定条件は VC の定義に従う。

**実施環境の区分**（docs/README.md「SWE.6 の実施方針」参照）:

| 区分 | 対象 | 本仕様での扱い |
|------|------|---------------|
| ホスト実行サブセット | 機能要求・電源状態要求の動作確認 | 本仕様の SWE6-TC-001〜006（CI で毎 PR 実行） |
| 実機 / HIL | タイミング制約・実 HW 依存要求・E2E | 本サンプル対象外（実プロジェクトで別冊管理） |

## 要求カバレッジ

全 SW 要求（機能・電源状態）に対して適格性テストケースが 1 件以上対応（100 %）。
I/F 要求（SW-REQ-200/201）はフルスタック構成での実行自体により統合検証（SWE5-TC-001/004 参照）、加えて Vehicle API 単体で SWE4-TC-101〜106 により検証済み。
